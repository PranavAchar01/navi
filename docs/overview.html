Rule 1. The STOP buzz never waits on an AI model.
Rule 2. Open Meta models by default (MapAnything, DINOv2, SAM 3.1, Glimmer). Muse Spark answers memory questions.
Rule 3. No faces or names: people are anonymous tracks. Background memory stays on the Mac. Small crops of the one item you asked about go to Meta's SAM 3.1 for 90 s, nothing otherwise.
